Anchor Bound
Anchor Bound is a full-stack, decentralized identity management and credential verification platform. It enables the secure issuance of permanent, non-transferable digital records in the form of Soulbound Tokens (SBTs) on the Polygon Amoy blockchain.

Core Features
Passwordless Authentication: Email-based One-Time Password (OTP) system for secure, password-free issuer access.

On-Chain Credentialing: Smart contracts deployed on the Polygon Amoy testnet to mint immutable digital certificates, academic degrees, and professional records.

Streamlined Issuance Dashboard: Clean interface for inputting recipient details and generating instant, publicly verifiable blockchain transaction hashes and token IDs.

Unified Architecture: Seamless communication between a Vite React frontend and an Express backend using local proxy routing.

Tech Stack
Frontend: React, Vite, TypeScript

Backend: Node.js, Express, Ethers.js

Database: TiDB Cloud, Drizzle ORM

Blockchain: Polygon Amoy Testnet, Hardhat, Solidity
